# Amanah: Your Daily Islamic Companion

[cite_start]**Amanah** (meaning "trust" or "responsibility" in Arabic) is a comprehensive mobile application designed to support Muslims in their everyday spiritual journey through an integrated, calming, and user-centered digital experience[cite: 14, 15]. [cite_start]Developed by **Nihaal Durrani** and team at the **National University of Computer and Emerging Sciences (FAST-NU)**[cite: 2, 7, 12].

## 🌟 Unique Value Proposition
Unlike many existing Islamic apps, Amanah distinguishes itself through:
* [cite_start]**Emotional Intelligence:** A unique system providing mood-based Surah recommendations to offer spiritual guidance tailored to your emotional state[cite: 21, 80].
* [cite_start]**Mindful Design:** A calm, distraction-free interface that promotes intentional engagement rather than addictive scrolling[cite: 81].
* [cite_start]**Holistic Growth:** Integrated goal setting and nightly reflection check-ins to help build consistent Islamic habits[cite: 22, 82].

## 🚀 Key Features
* [cite_start]**Core Worship:** Real-time prayer timings with countdowns, a digital Quran with audio recitation, and an accurate Qibla compass[cite: 18, 19].
* [cite_start]**Spiritual Growth:** Habit tracking for prayers and Quran reading with data-driven insights into religious habits[cite: 23, 46].
* [cite_start]**Learning & Knowledge:** Structured Seerah (Prophetic Biography) chapters, Islamic articles, and an Islamic calendar[cite: 25, 26, 27].
* [cite_start]**Scholar Connection:** A safe space to request guidance from verified Islamic scholars[cite: 31].

## 🛠️ Tech Stack
* **Frontend:** **Flutter** (for a cross-platform, aesthetically pleasing mobile experience)
* **Backend:** **Django** (handling core logic, user authentication, and API management)
* **Database:** **MongoDB** (storing flexible, document-based data for Quranic content and user logs)

## 🏗️ Architecture
[cite_start]The project utilizes a layered architecture to maintain a "Privacy-First" design[cite: 74]:
1.  [cite_start]**Mobile App (Flutter):** Presentation layer focusing on accessibility and modern UI[cite: 33, 41].
2.  [cite_start]**API Layer (Django):** Manages location-based services and notification logic[cite: 35].
3.  [cite_start]**Data Layer (MongoDB):** Securely handles sensitive personal and location data[cite: 74].

## 📋 Installation

1.  **Clone the repo:**
    ```bash
    git clone [https://github.com/Nihaal-Durrani/Amanah-Your_Islamic_Companion.git](https://github.com/Nihaal-Durrani/Amanah_Your-Islamic-Companion.git)
    ```
2.  **Backend Setup (Django):**
    ```bash
    cd backend
    pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver
    ```
3.  **Frontend Setup (Flutter):**
    ```bash
    cd frontend
    flutter pub get
    flutter run
    ```
